# Frontend

Vue 3 + TypeScript + Vite + Element Plus 前端目录。Phase 0 仅建立目录骨架，不包含可运行应用。

计划结构：

- `src/api`：类型安全的后端 API 客户端
- `src/components`：通用组件
- `src/layouts`：运营端和磅房端布局
- `src/router`：路由与权限守卫
- `src/stores`：跨页面状态
- `src/types`：共享 TypeScript 类型
- `src/views`：业务页面

Phase 1 将通过官方 Vite 脚手架初始化依赖、应用入口、检查脚本和 Dockerfile。
