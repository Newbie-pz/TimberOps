# TimberOps portfolio capture guide

Capture screenshots only from a real running TimberOps environment populated with non-sensitive demonstration data. Do not fabricate states or expose tokens, passwords, private keys, API keys, customer phone numbers, or real production identifiers.

## Recommended screenshots

1. Dashboard — daily tasks, net weight, income, status and ranking panels
2. Weighing Workbench — task summary and append-only tare/gross/reweigh history
3. Completed task reversal — two-step confirmation plus the resulting “已冲正” detail state
4. Billing Center — filters, payment state and reversal-frozen record
5. Reports — daily/monthly view and Excel export action
6. Audit Center — readable business target and `WEIGHING_REVERSED` event
7. AI Assistant — a read-only operational query with safe tool trace
8. User/RBAC — user roles and permission-aware navigation
9. GitHub Actions — green workflow for the exact release commit

Use a consistent browser viewport, hide bookmarks and unrelated applications, and verify that every screenshot reflects functionality present in the tagged release.
