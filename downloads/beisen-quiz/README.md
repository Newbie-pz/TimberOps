# 北森测评资料下载

本目录与 TimberOps 应用代码相互独立，仅用于存放可直接下载的刷题网页和题库 PDF。

## 文件

- `北森测评_单文件刷题网页.html`：离线单文件版本，下载后双击即可在浏览器中打开。
- `北森测评_单文件刷题网页.zip`：上述 HTML 的压缩包；如果浏览器把 HTML 当作页面打开而不是下载，优先下载 ZIP。
- `北森测评题库_总整理版.pdf`：354 页合并版，含封面、可点击目录和 PDF 书签，正文保留原始题图与可搜索文字。

## 内容

- 言语理解：805 题
- 图表分析：456 题
- 图形推理：152 题
- 合计：1,413 题

网页支持选项即时判定、正确答案与解析、题目搜索、随机题、未做题、错题筛选、答题进度本地保存和深浅主题切换。所有题图均嵌入 HTML，不依赖网络资源。
